# Luma 本地音乐播放器

一个简洁的本地音乐播放器，适合直接放到 GitHub 或 GitHub Pages 上使用。

## 功能

- 导入本地音频文件，支持多选和拖放
- 使用浏览器 IndexedDB 保存歌曲文件，刷新后仍然保留
- 记住当前歌曲和上次播放进度
- 搜索、排序、上一首、下一首、随机播放、单曲循环和音量控制
- 记录真实的听歌时长
- 按周日开始显示每日、每周和累计听歌统计
- 深色界面，适合长时间使用

## 本地数据说明

这是一个纯前端项目，不需要服务器，也不会上传歌曲。

- 歌曲文件保存在当前浏览器的 IndexedDB 中
- 播放进度和听歌统计保存在当前浏览器的本地存储中
- 更换浏览器、清理网站数据或使用隐私模式后，数据不会自动迁移
- GitHub 仓库中不会包含你导入的音乐文件

## 使用方式

直接打开 `index.html` 即可使用。首次打开后点击“导入本地音乐”，选择电脑里的音频文件。

如果浏览器限制了本地文件页面的部分行为，也可以在项目目录启动一个静态文件服务器，再打开对应地址。项目本身不需要安装依赖或构建。

## 发布到 GitHub Pages

1. 将项目中的 `index.html`、`styles.css`、`script.js`、`README.md` 和 `.gitignore` 上传到仓库。
2. 在仓库的 **Settings → Pages** 中选择从主分支的根目录发布。
3. 发布后打开 GitHub Pages 地址即可使用。

即使页面部署到了 GitHub Pages，歌曲和统计数据仍然只保存在使用者自己的浏览器中，不会进入 GitHub 仓库。
